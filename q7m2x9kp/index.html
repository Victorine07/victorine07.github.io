RepoSage — Production Agentic RAG System

Production LangGraph multi-agent RAG with hybrid retrieval, MCP server, sandboxed code execution, self-correction loops, and LLM-as-judge evaluation — 93.33% Pass@1, live on HuggingFace Spaces.

PythonLangGraphClaude APIQdrantBM25RRFFastAPIDockerMCPHuggingFace Spaces
GitHub · Live Demo
  • Retrieval pipeline: ingested the empyrical financial-metrics library at function level using AST-based chunking (122 functions); indexed dense embeddings (BAAI/bge-small-en-v1.5) in Qdrant and a parallel BM25 index; merged rankings via Reciprocal Rank Fusion (RRF) and reranked with a cross-encoder (ms-marco-MiniLM-L-6-v2) — combining lexical precision with semantic recall.
  • Agentic orchestration: designed a stateful LangGraph StateGraph with conditional cycles — retrieve → generate → execute → self-correct — and bounded retry logic (max 2 retries on execution failure); the agent autonomously diagnoses and repairs broken code without human intervention.
  • LLM integration: integrated Claude (Anthropic) and Gemini APIs via LangChain for code generation; implemented sandboxed subprocess execution with stdout/stderr capture; self-correction loop feeds execution errors back into the LLM for targeted fixes.
  • Evaluation: evaluated on a held-out 15-query gold set using an LLM-as-judge framework: 93.33% Pass@1, Context Recall 0.92, Faithfulness 0.88.
  • Production deployment: REST API (FastAPI, POST /query + GET /health) with Pydantic validation and auto-generated Swagger docs; Dockerized with python:3.11-slim; public Gradio app deployed on HuggingFace Spaces (ZeroGPU, free tier).
  • MCP server: built an MCPServer (mcp 2.x SDK) exposing three tools — search_empyrical (hybrid retrieval), execute_snippet (sandboxed execution), ask_reposage (full agent pipeline) — registered with Claude Desktop over stdio transport; verified end-to-end tool calls from live Claude Desktop conversations.
